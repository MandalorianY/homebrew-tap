# Homebrew Tap

Install Job Scrapper, a job scraper and Excel application tracker for France.

```sh
brew install mandaloriany/tap/job-scrapper
```

The formula is available after the first published Job Scrapper release. Run the command from the directory where you want to keep your data and exports.

[Job Scrapper source and usage](https://github.com/MandalorianY/job-scrapper)
